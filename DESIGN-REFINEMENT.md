# Exam Mate V2.1.4 — Design refinement notes

This release keeps the V2.1.3 component tree and interaction model intact. It makes a presentation-only refinement to the graphite, teal and ivory system.

- Stronger page and heading hierarchy, with more balanced line lengths and responsive type scaling.
- More intentional surface layering for the main photo card, text editor, history list, voice card and native player controls.
- Clearer section separators and grouped-list boundaries.
- More consistent button, icon-button and media-control tactile feedback.
- More deliberate selected navigation styling and light/dark surface treatment.
- Improved small-screen spacing and wrapping for phone widths.
- More visible keyboard focus states and retained reduced-motion accommodations.
- Admin statistics, license cards, status badges and toast notifications brought into the same visual language.

No React component hierarchy, routing, API contract, reading logic, speech recognition, native media action, licensing or persistence behavior was changed by the design pass.
